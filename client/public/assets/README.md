# Campus404 Asset Library

Static frontend assets live here so pages can reference stable public URLs.
Use `client/src/shared/assets.js` from React code instead of hardcoding paths.

## Structure

- `campus/` - campus and location imagery.
- `decorations/` - non-interactive decorative elements.
- `brand/` - Campus404 logo, favicon, and badge-style identity art.
- `icons/` - reusable UI and reward icons.
- `mascot/` - Opto/helper character poses and parts.
- `rewards/` - certificate and reward artwork.
- `tracks/` - track detail artwork, course props, and hero images.
